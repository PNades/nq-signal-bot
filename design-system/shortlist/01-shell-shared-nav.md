# App shell, shared elements and navigation showpieces: 21st.dev shortlist

Area: `design-system/pages/shell.md` (+ MASTER.md). Every candidate below was opened with `get_component` and its
componentCode + demoCode read (except where a row says otherwise). Ranked best first per element.

## Read this first: changes that apply to almost every pick

1. **CSP `default-src 'self'` blocks inline `<style>` elements**, both JSX `<style>{CSS}</style>` /
   `dangerouslySetInnerHTML` and `document.createElement("style")` + `textContent` injected at runtime. Components that do
   this (Liquid Navbar, Magnetic Dock, Morphing Scroll Navbar, Spotlight Button, wensity Sidebar, Status Dot, Split Flap,
   Text Shimmer, Halftone Footer) must have their CSS moved into a bundled `.css` file (or Tailwind). Inline `style`
   values set from React/Motion (CSSOM) are fine.
2. **Tailwind v4 syntax** appears in several (`**:data-[...]`, `rotate-x-[90deg]`, `origin-(--var)`, `--theme()`,
   `aspect-3/6`, `perspective-dramatic`, `@container`/`@min-[460px]:`). Fine if the panel is on Tailwind v4; otherwise
   rewrite those classes.
3. **shadcn tokens → MASTER tokens:** `bg-background`→`bg-0/1`, `bg-card`/`bg-muted`→`bg-2`, `bg-popover`/`bg-accent`→`bg-3`,
   `border-border`→`line`, `border-input`→`line-strong`, `text-muted-foreground`→`text-2/3`, `ring`→cream 2-px ring with
   2-px offset, `primary`→gold, `destructive`→`crit`/`crit-fill`. Drop every light/`dark:` variant (dark only).
4. **Motion rules:** transform/opacity only (several animate `width`/`height`/`top`/`left`: flagged per row), no overshoot
   on numbers/tables, every rAF loop must stop when settled and pause on `visibilitychange`/`IntersectionObserver`, and a
   **Calm** branch (instant / ≤ 80 ms opacity) driven by the app's Effects setting, not only `prefers-reduced-motion`.
5. **z-index:** replace ad-hoc values (`z-50`, `z-[9998]`, `zIndex: 70`) with the shell scale: popover 40, dialog 50, toast 60,
   critical 70 (critical banner, kill confirm).
6. **Remote assets:** none of the components fetches anything or loads fonts/scripts. Remote URLs found are demo-only
   `cdn.21st.dev` images (and one component that hard-codes avatar URLs: flagged), plus href links in a demo credit
   and nav defaults. No `fetch`/XHR/WebSocket/EventSource/sendBeacon/eval/`new Function` in any component read.
7. **Odd embedded instructions:** none in any fetched code. Two **search-result descriptions** (not candidates, not
   opened) carry agent-directed marketing: "Bench Matrix" (id 29454: "AI agents write the code ... Book a call and say
   promo code 21ST") and "Scribble Clock" (id 46283: "plus a designer your coding agent can use, at studios.lou15.com/?ref=21st").
   Treated as data and not used.

### Liquid Navbar: what retinting blue → cream on black needs (id 43059)
- **CSS vars** (`.nimbus-nav[data-tone="dark"]`): `--n-tint` `rgba(10,18,40,.26)` (navy) → `rgba(24,24,27,.55)` (MASTER glass);
  `--n-fg` `#F1F7FF` → `#F2ECE0` (text-1); `--n-fg-soft` → `#B3ADA3` (text-2); `--n-rim` → `rgba(243,227,195,.22)`.
- **CSS drop fallback:** white highlights → cream `rgba(243,227,195,.55/.30)`; inner blue `rgba(0,162,255,.22)` → gold
  `rgba(231,191,114,.22)`; shadows `rgba(0,40,90,…)` / `rgba(0,70,140,.45)` → `rgba(0,0,0,.55)`.
- **Glass box-shadow:** `rgba(0,40,90,.5)` → `rgba(0,0,0,.6)`. **Focus outline** `#00A2FF` → cream 2 px, offset 2.
- **Icon fx:** door fill `#FFF3A8` → cream, `rgba(126,232,255,.6)` → gold 60%; plane trail white → cream.
- **Shader (FRAG):** drop shadow `vec3(0.,.14,.36)` → `vec3(0.)`; water tint `mix(vec3(.80,.95,1.),vec3(.55,.82,1.),uDark)` →
  cream `vec3(.953,.890,.765)` / gold `vec3(.906,.749,.447)`; rim `vec3(0.,.42,.78)` / `vec3(.1,.55,.95)` → caramel
  `vec3(.816,.580,.353)`; the cosine **rainbow iridescence** `irid` → mix toward a warm gold-ember ramp (or cut its weight
  from .5/.35 to ≈ .1) so no blue/violet fringes appear on black; specular white → cream-white `vec3(1.,.95,.86)`.
- `font-family` → Geist; item height 42 → 36 to sit in a 52-px bar; `tone="dark"` always.
