# Forms and surfaces shortlist: Accounts, Settings, Gameplan, surface showpieces

Step 14a part 0, step 3. Sources: 21st.dev MCP only (`search`, `get_component`). Every candidate below had its
componentCode and demoCode read. No generate, submit, edit, delete or bookmark tool was called. Nothing was installed and
nothing was written in the repo.

**Injected instructions:** none found. No component, demo or description held text aimed at an AI or agent.

**Remote calls:** no component makes a `fetch`, XHR, WebSocket, EventSource or beacon call, and none uses `eval` or
`new Function`. Remote assets show up only in demos or comments, each noted in its row. One component has a remote image
hard-coded in the component itself: the Motion Tilt card (24971), which is rejected.

**What the strict CSP (`default-src 'self'`) means for these:**
- `<style dangerouslySetInnerHTML>` is blocked unless `style-src` allows `'unsafe-inline'`. Three candidates do this:
  AnimatedGrid 29376 and BorderBeamPanel 23408, plus the `style=""` attribute in LiquidGlass 40333's injected SVG. Their
  CSS goes into a static `.css` file. React `style={{}}` props are fine (they are set through the CSSOM).
- Blob-URL images need `img-src 'self' blob:`. Two candidates use them: LiquidGlass 40333 (its displacement map) and the
  joyco dropzone 19201 (image previews).
- The shadcn Sidebar block (28366) writes `document.cookie`. It is local only and harmless, but it should be removed.
- Several candidates import "-utils" files that the registry did not return. They are marked "partly unreviewed".
