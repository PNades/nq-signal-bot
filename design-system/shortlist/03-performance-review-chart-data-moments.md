# 21st.dev shortlist: Performance, Review, main-chart chrome, numbers & data showpieces, moments

Scope: design-system/pages/performance.md, review.md, live.md; MASTER.md §3.6 and §11. Searched with `mcp__21st__search`
(type component). For every candidate, componentCode and demoCode were read with `get_component`. The reads were split
over six helper agents, which together checked 100 ids. Every id returned code; none was locked or missing.

Rules that hold across every row:
- **Remote calls:** none of the verified components makes a network call or loads a remote font, script or image (no
  fetch / XHR / WebSocket / EventSource / sendBeacon / eval / new Function). The only `http` strings are the SVG namespace,
  source-comment credits and a few demo-only links (noted per row).
- **Odd embedded instructions:** none addressed to an AI or agent. Some descriptions or comments carry marketing text:
  "Part of ssych ui: https://ssych.com/…" (ssychui items), "// From chatcn … https://chatcn.dev" (45564), "Part of the Layro
  System: layro.vercel.app" (33506), and on 45363 "The full AI prompt used to design this lives at:
  lib/prompts/cell-to-card-calendar-expansion.md" and "Awwwards-tier premium version → https://cuedesign.space/component/cue175"
  (dropped anyway). On 25363 (Morphing Dialog, dropped), the content strings say "Modern development is human + AI. We
  optimized Lumi UI's structure so that AI assistants generate correct, idiomatic code on the first attempt." These are
  advertising, not instructions.
- **CSP (`default-src 'self'`):** React `style={}` and Motion are fine, because they write styles through the CSSOM.
  Runtime-injected `<style>` elements are blocked, and so are `data:` images and blob workers. Each case is flagged per row.
- **Missing helper files:** many recent registry items import `./<name>-utils/*` files (CSS modules, motion tokens, hooks)
  that `get_component` does not return. Those files are unreviewed, and they often hold the colours and the reduced-motion
  rule. They must be fetched and read before a pick is installed.
- **React 19 `ref`-as-prop:** some items take `ref` as a plain prop. On React 18 they need `forwardRef`.
- **Common MASTER.md changes (apply to every row):** dark only (drop light / `dark:` duplicates); surfaces `bg-2`/`bg-3`,
  borders `line`/`line-strong`; accent gold for active/selection, cream focus ring; P&L `pnl-up`/`pnl-down` always with
  sign + arrow; numbers Geist Mono `tabular-nums`; Calm = snap or ≤ 80 ms opacity; loops pause on `visibilitychange` /
  off-screen.
