# Pattern: Rug Setup

## Definition

A rug setup is a positive gamma node stacked directly above one or more negative gamma nodes, with spot price below the positive gamma node. It is not just resistance. It is rejection with acceleration behind it.

## Structure

- Positive gamma node stacked above
- Negative gamma node(s) directly below it
- Spot price is below the positive gamma node

## Behavior

| Node | Effect |
|---|---|
| Positive gamma node (above) | Rejection |
| Negative gamma node(s) (below) | Fuels continuation lower |

**Sequence:** Price pushes into the structure → gets rejected → expands lower.

## Mental Model

A ceiling that not only blocks price, but pushes it down faster once rejected.
