# Heatseeker Patterns — Key Takeaways

## 1\. Hierarchy of Influence

Ranked from most to least important:

1. Node magnitude  
2. Gamma regime  
3. Pattern structure  
4. Cross-index alignment

## 2\. How to Think About Pattern Interaction

When multiple patterns exist, ask these questions:

| Question | What to look for |
| :---- | :---- |
| Which pattern creates movement? | Negative gamma → fast moves. Overshoot → reversion. |
| Which pattern slows movement? | Positive gamma clusters. Large nodes. |
| Which has more magnitude? | Magnitude overrides everything. |

## 3\. Common Mistakes

| \# | Mistake | Correction |
| :---- | :---- | :---- |
| 1 | Treating patterns as signals | "This is a rug, so it will dump" is wrong. Patterns are not signals. |
| 2 | Ignoring magnitude | A small node does not mean strong influence. |
| 3 | Ignoring regime | Negative gamma behaves differently than positive gamma. |
| 4 | Ignoring chart structure | No structure \= no trade. Always: charts first, Heatseeker second. |
| 5 | Overconfidence in one pattern | One pattern is never enough. |

## 4\. Key Takeaways

| Pattern / Concept | Meaning |
| :---- | :---- |
| Patterns (general) | Describe behavior, not direction |
| Magnitude vs. color | Magnitude matters more than color |
| Pika clouds | Friction, not bias |
| Rug setups | Rejection \+ continuation |
| Beach ball | Overshoot, not breakout |
| Rainbow | Stand down (no trade) |
