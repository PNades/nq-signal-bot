# Pattern: Reverse Rug Setup

## Definition

A reverse rug setup is a negative gamma node stacked on top of a positive gamma node, with spot price above the positive gamma node. It is support with pro-cyclical momentum. It is the opposite of a rug setup.

## Structure

- Negative gamma node on top
- Positive gamma node below
- Spot price is above the positive gamma node

## Behavior

| Node | Effect |
|---|---|
| Positive gamma node (below) | Deflects price back upward |
| Negative gamma node (above) | Fuels the deflection back up |

**Sequence:** Price dips → holds → reverses with momentum.

## Mental Model

Instead of rejection downward, you get a hold and a bounce.
